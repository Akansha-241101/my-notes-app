# Product Requirements Document

## Goal

Provide a clean, beginner-friendly dashboard for capturing, organizing, finding, editing, and deleting personal notes.

## In scope

- Create a note with title, content, and optional tag.
- Read notes, search title/content, favorite/unfavorite, edit, and permanently delete.
- All Notes and Favorites filters, responsive light/dark UI, and transient status feedback.

## Out of scope

Authentication, sharing, collaboration, payments, and permanent Trash restore behavior.

## User stories and acceptance criteria

- As a user, I can write and save a titled note. It appears in All Notes.
- I can search title or content and filter favorites.
- I can edit, favorite, and delete a note through its card controls.
- I can switch themes and see my selection again after reload.
- I see loading, empty, successful, and failed-operation feedback where relevant.
- The layout remains usable at mobile and desktop widths.
